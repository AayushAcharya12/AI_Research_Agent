# 🤖 AI Research Agent

An AI-powered research assistant that searches the web and provides accurate, concise answers to user queries. It uses **LangGraph** for agent workflows, **LangChain** for orchestration, **Groq LLM** for response generation, and **Tavily Search** for real-time web search.

### Technologies Used

* Python
* LangChain
* LangGraph
* Groq API
* Tavily Search
* Streamlit

### Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
